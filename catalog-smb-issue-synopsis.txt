1. THE PROBLEM
--------------
Jocala Catalog (com.jocala.catalog) cannot load its library. Every launch
fails reading the live Calibre database over SMB:

  "Could not reach the Calibre database at
   smb://192.168.1.39/ebooks/calibre/metadata.db.
   nwerror: posixerrorcode(rawvalue: 50): network is down …"

App log (~/Library/Application Support/com.jocala.Catalog/app_log.txt),
identical on every failing run (22:09, 22:12, 22:29, 22:31, 22:32, 22:35):

  [22:12:01.865] I/ReaderLog: === App Start ===
  [22:12:01.865] I/SMB: download transient/non-auth failure, retrying
      host=192.168.1.39 err=NWError: … (Network.NWError error 50 - Network is down)
  [22:12:02.720] E/SMB: download retry failed host=192.168.1.39 err=NWError … error 50
  [22:12:02.721] E/CatalogStore: load failed mode=Books Could not reach …

Both the initial attempt AND the built-in retry (~800 ms later) die with
NWError posix 50 (ENETDOWN) at TCP-connect time — before any SMB bytes,
before authentication. The error dialog is produced by
CatalogDBError.network in Sources/CatalogSwiftApp/SmbCatalogDB.swift:63-64.

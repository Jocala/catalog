Jocala Catalog Help

Jocala Catalog browses your Calibre ebook library — over your home network (SMB) or from a local Calibre folder — and can open books directly on your Kobo e-reader. Mac and Windows versions work the same way; differences are marked.

1. Getting started

  1. Open Settings (toolbar button).
  2. Pick a library source: SMB (a Calibre library on another computer or NAS) or Local (a Calibre folder on this computer).
  3. Fill in the details (see §6), press the Test buttons until you see Pass, then Save — the library reloads when the source changed (a password, Kobo, or theme-only change costs nothing).
  4. Your books appear in the main window. If the window is empty, it will point you back to Settings.

2. Browsing the library

  • Browse picker — switch the gallery root between Books, Author, Series, and Tags.
  • Sort picker — the choices depend on the view: Books offers Author, A–Z, Z–A, Newest, Oldest; Author offers A–Z, Z–A; Series offers Author, A–Z, Z–A; Tags offers A–Z, Z–A.
  • Grid / List — toggle cover tiles or a compact list.
  • Drill in — click an author, series, or tag tile to see its books; use ‹ Back Windows (the gallery resets when you switch views) to return.
  • Reload — re-reads the library, picking up books you added in Calibre.
  • The header shows the book/author/series/tag count, or status messages while the Kobo is working.
  • Right-click a tile Windows for Show Details, Open on Kobo, and Copy Kobo query.

3. Searching

  • Press the 🔍 Search button to open the search form.
  • All-fields box — matches across title, author, series, and tags. It understands prefixes: author:asimov, tag:espionage.
  • Title / Author — match those fields only.
  • Series / Tag lists — pick from every series and tag in your library, with book counts.
  • “Select series if any book matches tag” — when only a tag is given, show the matching series instead of a flat book list.
  • Press Search (or Enter); Cancel (or Esc) closes the form. Search needs at least one filled field.
  • Results replace the library view; press the Library button to go back. Click a result to open its details.

4. Book details

Click a book (or double-click a list row Windows) to open its details: cover, title, author, series + number, tags, publisher, ISBN, and description.

  • Read on Kobo — opens the book on your Kobo (see §5).
  • Close (or Esc) returns to the library.

5. Reading on Kobo

  1. In Settings → Kobo, add your Kobo's IP address (find it on the device under Settings → Wi-Fi). The Kobo must be awake and on the same network.
  2. Optionally store the Kobo's SSH password per IP; leave it empty for key-only login.
  3. Open a book and press Read on Kobo. The app finds the matching file on the device and opens it in KOReader.
  • Stacking fix (first run) — KOReader can pile up instances; the app offers to install a tiny, reversible fix. Install applies it, Not Now skips it (you won't be asked again).
  • Not on Kobo — if the book isn't on the device, the app offers Sync & Open, copying it over Wi-Fi (the size is shown first) and then opening it.
  • Fail-closed — if several files could match, or none can be confirmed, the app tells you instead of opening the wrong book.
  • Kobo asleep? — “sleeping or unreachable” means what it says: press the Kobo's power button to wake it and try again.
  • Password rejected — means the stored SSH password for that IP is wrong; fix it in Settings → Kobo.
  • The ★ star in Settings marks the default Kobo used for reading.

6. Settings reference

  • Library Source — SMB or Local (either-or).
  • Local Calibre Path — the Calibre folder (the one containing metadata.db). Browse picks it; Test checks it and shows Pass/Fail.
  • SMB Server — hostname or IP of the computer sharing the library; Test SMB checks the connection (Pass/Fail).
  • Share — the shared folder name.
  • SMB Calibre Path — folder inside the share holding metadata.db (e.g. calibre/); Test Calibre verifies it (Pass/Fail).
  • User / Password / Domain — SMB login. Password can be revealed with Show and is always masked otherwise.
  • Kobo list — Add rows by IP; click the ★ star to mark the default; edit IPs and passwords in place; Show/Hide reveals a password; Test pings the device (Pass/Fail pill); the red 🗑 trash removes a row.
  • Theme — System, Light, or Dark. System follows the OS.
  • Open Data Folder — opens the app's data folder (§9).
  • Save / Cancel — Save applies the settings and closes, re-reading the library only when the library source or its credentials changed.

7. Menus & shortcuts

  • File → New Window — open another library window (Cmd+N Mac, Ctrl+N Windows).
  • File → Open Data Folder Windows / app menu Mac (Cmd+O) — §9.
  • File → Settings… Windows (toolbar button on both).
  • File → Exit Windows.
  • Help → Jocala Catalog Help — this page.
  • About Jocala Catalog — app menu Mac, Help menu Windows; version, links, donations (§8).
  • In dialogs: Enter confirms (Search, Read on Kobo), Esc closes.

8. About & donations

Donations defray server costs and fund development. The About dialog carries a Donate button that opens the PayPal donation page, plus a link to jocala.com. Thank you!

9. Your data & passwords

  • Settings and caches live in ~/Library/Application Support/com.jocala.Catalog/ Mac or %APPDATA%\com.jocala.Catalog\ Windows (book covers and thumbnails are cached in subfolders there).
  • Mac passwords are kept in the Keychain; Windows passwords are kept in the local settings file. Passwords are masked everywhere except the momentary Show buttons, and are never displayed in full.
  • Never enter credentials anywhere except Settings.

10. Troubleshooting

  • Can't connect / empty library — open Settings and work through the Test buttons: Test SMB, then Test Calibre (or Test for a local folder). Check server name, share, path spelling, and login.
  • “Sleeping or unreachable” — wake the Kobo with its power button, confirm Wi-Fi, and check the IP hasn't changed.
  • “Password rejected” — re-enter the Kobo SSH password in Settings.
  • Wrong book / ambiguous match — the app refuses to guess; refine the Calibre title/author so the match is exact.
  • Database errors — the error dialog offers Open Settings and Retry; a Calibre-side library repair fixes persistent cases.

Jocala Catalog Help

Jocala Catalog browses your Calibre ebook library — over your home network (SMB) or from a local Calibre folder — and can open books directly on your Kobo e-reader. The Windows, macOS, and Linux versions work the same way.

1. Getting started

  1. Open Settings (toolbar button).
  2. Pick a library source: SMB (a Calibre library on another computer or NAS) or Local (a Calibre folder on this computer).
  3. Fill in the details (see §7), press the Test buttons until you see Pass, then Save — the library re-reads with the new settings.
  4. Your books appear in the main window. If the window is empty, it will point you back to Settings.

2. Kobo setup (do this once)

Reading and syncing need three things on the device: KOReader installed, the Kobo's own SSH server turned on (port 22), and the Kobo awake on your home Wi-Fi so you can reach it by IP address (find it on the device under Settings → Wi-Fi). Do this once; the app remembers the rest in Settings.

  1. Install KOReader — the one-click packages bundle KOReader with its launcher: One-Click Install Packages for KOReader & Plato (see also the MobileRead KOReader wiki). Plug the Kobo in over USB, extract the package to the root of the device, eject, and let it reboot.
  2. Turn on the Kobo's SSH server — on current firmware, connect over USB and rename .kobo/ssh-disabled to .kobo/ssh-enabled, then reboot. Afterwards ssh root@<device_ip> prompts you to set the root password on first connect (enabling SSH; credentials and password notes).
  3. Don't confuse the two SSH servers — KOReader also ships a Dropbear plugin on port 2222 (details). Jocala Catalog uses the device SSH server on port 22.
  4. Key login (recommended) — the first-run stacking-fix check needs key login; password-only Kobos skip the offer silently (see §6). Add the Kobo's IP in Settings → Kobo, store the SSH password or a key, and press Test until you see Pass.
  • Same network, awake, stable IP — the Kobo must be awake and on the same network as this computer. Kobos sleep aggressively: press the power button before reading. If the router reassigns the IP, update it in Settings → Kobo (see Troubleshooting).

3. Browsing the library

  • Browse picker — switch the gallery root between Books, Author, Series, and Tags.
  • Sort picker — the choices depend on the view: Books offers Author, A–Z, Z–A, Newest, Oldest; Author offers A–Z, Z–A; Series offers Author, A–Z, Z–A; Tags offers A–Z, Z–A.
  • Grid / List — toggle cover tiles or a compact list.
  • Drill in — double-click (or press Enter on) an author, series, or tag tile to see its books; the ‹ Back toolbar button returns to the gallery.
  • Reload — re-reads the library, picking up books you added in Calibre.
  • The status bar at the bottom shows the book/author/series/tag count, or status messages while the Kobo is working.
  • Right-click a tile for Show Details and Open on Kobo.

4. Searching

  • Press the 🔍 Search button to open the search form.
  • All-fields box — matches across title, author, series, and tags. It understands prefixes: author:asimov, tag:espionage.
  • Title / Author — match those fields only.
  • Series / Tag lists — pick from every series and tag in your library, with book counts.
  • “Expand tag to series” — when only a tag is given, show the matching series instead of a flat book list.
  • Press Search (or Enter); Cancel (or Esc) closes the form. Search needs at least one filled field.
  • Results replace the library view; press the Library button to go back. Click a result to open its details.

5. Book details

Double-click a book (or press Enter) to open its details: cover, title, author, series + number, tags, publisher, ISBN, and description.

  • Read on Kobo — opens the book on your Kobo (see §6).
  • Close (or Esc) returns to the library.

6. Reading on Kobo

  1. In Settings → Kobo, add your Kobo's IP address (find it on the device under Settings → Wi-Fi). The Kobo must be awake and on the same network.
  2. Optionally store the Kobo's SSH password per IP; leave it empty for key-only login.
  3. Open a book and press Read on Kobo. The app finds the matching file on the device and opens it in KOReader.
  • Stacking fix (first run) — the first time you read on a Kobo, the app checks for the stacking fix (KOReader piling up instances when opening book after book) and offers to Install it — a tiny, reversible change on the device. Not Now skips it and you won't be asked again. The Install stacking fix button in Settings → Kobo does the same on demand for the active Kobo. Reading goes ahead either way. The check needs key login, so password-only Kobos skip the offer silently.
  • Not on Kobo — if the book isn't on the device, the app offers to copy it over Wi-Fi (the size is shown first) — press OK to sync and open.
  • Fail-closed — if several files could match, or none can be confirmed, the app tells you instead of opening the wrong book.
  • Kobo asleep? — “sleeping or unreachable” means what it says: press the Kobo's power button to wake it and try again.
  • Password rejected — means the stored SSH password for that IP is wrong; fix it in Settings → Kobo.
  • The ★ star in Settings marks the default Kobo used for reading.

7. Settings reference

  • Library Source — SMB or Local (either-or).
  • Local Calibre Path — the Calibre folder (the one containing metadata.db). Browse picks it; Test checks it and shows Pass/Fail.
  • SMB Server — hostname or IP of the computer sharing the library; Test SMB checks the connection (Pass/Fail).
  • Share — the shared folder name.
  • SMB Calibre Path — folder inside the share holding metadata.db (e.g. calibre/); Test Calibre verifies it (Pass/Fail).
  • User / Password / Domain — SMB login. Password can be revealed with Show and is always masked otherwise.
  • Kobo list — Add rows by IP; click the ★ star to mark the default; edit IPs and passwords in place; Show/Hide reveals a password; Test checks the SSH connection (Pass/Fail pill); the 🗑 trash removes a row.
  • Theme — System, Light, or Dark. System follows the OS.
  • Check for updates at startup — on for new installs; Catalog checks for a new version at launch (silent unless one is ready).
  • Diagnostic logging — off for new installs; when on, every library load appends a timing line to errors.log (see §10). Nothing extra is logged when it is off.
  • Save / Cancel — Save applies the settings, closes, and re-reads the library.

8. Menus & shortcuts

  • File → New Window — open another library window (Cmd+N Mac, Ctrl+N Windows/Linux).
  • File → Open Data Folder — §9.
  • File → Settings… — or the toolbar Settings button.
  • File → Exit quits the app.
  • Help → Jocala Catalog Help — this page.
  • About Jocala Catalog — version, links, donations, and a Check for Updates button. On Windows/Linux it's under Help; on Mac it's under the JocalaCatalog application menu (as are Settings… and Quit, which leave the File menu). Help → View Changelog opens the release notes. Catalog checks for updates at startup (silent unless one is ready); turn it off with Settings → General → Check for updates at startup.
  • In dialogs: Enter confirms (Search, Read on Kobo), Esc closes.

9. Your data & passwords

  • Settings and caches live in ~/Library/Application Support/com.jocala.Catalog/ Mac, %APPDATA%\com.jocala.Catalog\ Windows, or ~/.local/share/Jocala Software/Jocala Catalog/ Linux (book covers and thumbnails are cached in subfolders there). File → Open Data Folder opens it.
  • Passwords are kept in settings.json in that folder on all platforms (deliberately outside the OS keychain, so there is never a keychain prompt). Passwords are masked everywhere except the momentary Show buttons, and are never displayed in full.
  • Never enter credentials anywhere except Settings.

10. Troubleshooting

  • Can't connect / empty library — open Settings and work through the Test buttons: Test SMB, then Test Calibre (or Test for a local folder). Check server name, share, path spelling, and login.
  • “Sleeping or unreachable” — wake the Kobo with its power button, confirm Wi-Fi, and check the IP hasn't changed.
  • “Password rejected” — re-enter the Kobo SSH password in Settings.
  • Wrong book / ambiguous match — the app refuses to guess; refine the Calibre title/author so the match is exact.
  • Database errors — the error dialog offers Open Settings and Retry; a Calibre-side library repair fixes persistent cases.
  • Slow first loads — the first load after setup or Reload reads the whole library over the network; later loads reuse a local copy (smb-metadata.db next to the covers cache) and are much faster. Reload always fetches fresh.
  • Reporting a library problem — turn on Settings → General → Diagnostic logging, reproduce the slow load or error once, then open File → Open Data Folder and attach errors.log. It carries one timing line per load (fetch attempts, pool state, byte counts — never passwords) plus the exact error text.
